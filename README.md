# Αγρολόγιο

Πρόγραμμα για Windows που καταγράφει τα έξοδα και τα έσοδα των αγροτικών εργασιών (ελιά, αμπέλι) και βγάζει το καθαρό κέρδος ανά αγροτεμάχιο και καλλιέργεια.

## Εγκατάσταση

Κατεβάστε το `Agrologio-Setup-x.y.z.exe` από τα [Releases](https://github.com/Nikos-1/agrologio/releases/latest) και τρέξτε το. Τα Windows μπορεί να δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας», γιατί το πρόγραμμα δεν έχει ψηφιακή υπογραφή: πατήστε «Περισσότερες πληροφορίες» και μετά «Εκτέλεση οπωσδήποτε».

Από την έκδοση 0.2.0 και μετά το πρόγραμμα ενημερώνεται μόνο του: ελέγχει για νέα έκδοση κατά την εκκίνηση, την κατεβάζει στο παρασκήνιο και ρωτά αν θέλετε επανεκκίνηση. Χειροκίνητος έλεγχος: Βοήθεια → Έλεγχος για ενημερώσεις.

## Τα στοιχεία σας

Τα στοιχεία μένουν μόνο στον υπολογιστή σας, στο αρχείο SQLite `katastixo.sqlite` (Αρχείο → Άνοιγμα φακέλου δεδομένων το δείχνει). Μια ενημέρωση δεν τα αγγίζει, και πριν από την πρώτη εκκίνηση κάθε νέας έκδοσης κρατιέται αντίγραφο στον υποφάκελο `backups`.

## Για προγραμματιστές

- `web/agrologio.html`: όλη η εφαρμογή (μία σελίδα HTML/JS).
- `build-app.js`: φτιάχνει το `app/` από τη σελίδα, με τοπικές βιβλιοθήκες και γραμματοσειρές.
- `main.js`, `preload.js`, `shim.js`: Electron, βάση SQLite (sql.js) και αυτόματες ενημερώσεις (electron-updater).

```
npm install
npm start          # δοκιμή
npm run dist       # Windows installer στο dist/
```

Νέα έκδοση: αλλάξτε το `version` στο `package.json`, τρέξτε `npm run dist` και ανεβάστε στο GitHub Release `vX.Y.Z` τα `Agrologio-Setup-X.Y.Z.exe`, `.exe.blockmap` και `latest.yml`.
